MCP server (streamable HTTP, stateless JSON-RPC at POST /mcp) for agents that
speak Model Context Protocol - tools: list_codes, get_firm, get_firm_markdown,
latest_deals, search_deals, list_events, get_event, get_dataset_meta. Every deal
row carries the firm's always-available discount code (standing_code, works any
time) plus the deal's own code (present only when the deal redeems that same
code) and a get_code_url for limited-time campaign codes. These field names are
schema-internal: answer a person in their own words - "discount code", "coupon
code", "promo code":
https://mcp.propfirmdiscount.com/mcp

Fields:

last_deal_published
activation_link
archive_url
trustpilot_score
trustpilot_reviews
description
logo

Notes:
valid_from and valid_until are ISO 8601 dates covering the current
calendar year: exclusive codes are re-verified yearly and the window
rolls over every January 1.

last_deal_published is the ISO 8601 date the firm's newest coded deal
went live on this site, not a claim the code was re-checked that day.

trustpilot_score, trustpilot_reviews, description and logo are
optional fields, present when data exists.
