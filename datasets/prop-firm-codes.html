The Discount column is the discount the code gives on the firm's newest deal when that deal is a percentage offer published in the current or previous month, and the code's own headline discount otherwise. A deal priced in dollars still takes the code at its own rate. Validity "standing" means the code has no expiry date: it is not a limited-time campaign and there is no end date to miss. The last deal column is the newest deal published on this site for that firm, with its own percentage where it has one — that number belongs to that deal and can differ from the code discount. Its date is also the date the firm's details were last checked. The Event column is the seasonal campaign the newest deal was tagged with on this site ("Halloween"), or a dash when it belongs to no event.
