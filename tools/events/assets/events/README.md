# Icon assets

Drop the real artwork here with these exact names, then rebuild — the builder
copies them verbatim into the dist root and they replace the placeholder
`favicon.svg` automatically:

- favicon.svg
- favicon.ico
- favicon-96x96.png
- apple-touch-icon.png
- web-app-manifest-192x192.png
- web-app-manifest-512x512.png

Same naming as `tools/satellites/assets/s1/`; the `<head>` already points at
all of them.
